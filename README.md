# HealthTrack Dashboard

## 🚀 Project Spotlight
Excited to share the launch of **HealthTrack Dashboard** – a modern health tracking web app that helps users log, monitor, and visualize daily health metrics like weight, steps, calories, and blood pressure.  

**🎯 Project Overview:**  
Developed a high-performance, fully responsive dashboard with goal tracking, reminders, and interactive charts to empower users in maintaining a healthy lifestyle.  

**💡 Result:** Improved user engagement and health monitoring with interactive data visualization and easy-to-use interface.  

---

## 🌟 Features
- User authentication (login, logout, profile)
- Log daily health metrics: weight, calories, steps, blood pressure
- Track goals and progress with interactive progress bars
- Set and view reminders for daily health activities
- Visualize historical data with charts (weight, steps, calories)
- Export data to CSV or PDF
- Responsive modern UI/UX
- High performance and smooth user experience

---

## ⚡ Technical Highlights
- **Backend:** PHP with MySQL
- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **Responsive Design:** Tailwind CSS-inspired styling
- **Deployment:** XAMPP for local development
- **Session Management:** PHP Sessions for authentication
- **Data Visualization:** Interactive charts for health metrics
- **Export Functionality:** CSV & PDF export
